# Code of conduct

## Scope

This applies to issues, pull requests, discussions, and any other space where
you are representing this project.

## Expected behaviour

- **Argue with the code, not the person.** "This force term is wrong because
  the measurement shows 1/d" is fine. "You clearly don't understand physics"
  is not.
- **Bring evidence.** This project has a strong preference for measured claims
  over confident ones. A number beats an opinion, and "I measured X on this
  input" beats "this is obviously how it works".
- **Assume the other person read the code.** Most surprising behaviour here has
  a reason recorded in a comment. Ask why before assuming carelessness.
- **Accept that a correction can be wrong too.** Changing your mind is welcome;
  flip-flopping without evidence is not.

## Unacceptable behaviour

- Harassment, insults, or personal attacks.
- Discriminatory comments about identity, background, or experience level.
- Publishing someone's private information without permission.
- Sustained disruption of discussions.
- **Committing real memory ledgers or personal data.** The ledger records
  someone's actual judgments and conversations. Attaching one to a public issue
  is a privacy violation, not a bug report. Use a redacted reproduction.

## Reporting

Report concerns to the repository owner through GitHub. Reports are read and
acted on. Maintainers may remove comments, close issues, or block accounts.

## Attribution

This document is written for this project rather than adapted from a template,
because the two rules that matter here — evidence over confidence, and never
publish a real ledger — are specific to what this repository does.
