# Security policy

## Reporting a vulnerability

Please do not open a public issue for a security vulnerability. Contact the repository owner through GitHub first and include:

- a short description of the impact;
- reproducible steps or a minimal proof of concept;
- the affected version or commit;
- any suggested mitigation.

The plugin stores its ledger locally. Do not attach a real ledger if it contains private conversations or personal data; use a redacted reproduction instead.
